# Techno International New Town website

A responsive, multi-page public website for Techno International New Town. It introduces the institute, presents its academic programmes, explains the admissions journey and makes contact and campus directions easy to access.

## Technology

- TanStack Start and React
- TypeScript
- Tailwind CSS with a custom responsive design system
- Lucide icons
- Netlify deployment configuration

## Run locally

Install dependencies with `pnpm install`, then run `pnpm dev`. The local Vite server is available at the address printed in the terminal.

## Structure

Routes live in `src/routes`, shared branding and navigation are in `src/components`, and programme information is kept in `src/data/site.ts`. Local photography is stored in `public/images`.
